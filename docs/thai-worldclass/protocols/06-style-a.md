# A_ONE_COLUMN — Global Preprint (Mandatory House Profile)

Purpose: theory, philosophy, social science, methods, long-form research, readable arXiv/preprint output.

Reference source: `latex/examples/A_worldclass_onecolumn.tex`
Reference PDF: `latex/examples/A_worldclass_onecolumn.pdf`

## Semantic precedence

A visual profile MUST NOT override Thai semantic breathing. Compose meaning/thought units first; apply this profile afterward.

## Visual grammar

- A4, one column, calm page color.
- Restrained running identity and bottom metadata.
- Page `x / y`.
- Article type above title.
- Title dominant but not magazine-like.
- Author + ORCID, affiliation, corresponding author, update/version line.
- Abstract enclosed by subtle rules, not a decorative card.
- Keywords and compact metadata block.
- Conservative section hierarchy.
- Equations centered with standard numbering.
- Tables use booktabs and semantic text reflow.
- Running header uses author on left, short title on right.
- Footer supports status/license, page x/y, and DOI/article ID when real.

## Hard failures

A output MUST fail release if:

- Thai body rhythm is mechanically repetitive;
- abnormal stretched gaps remain;
- metadata is fabricated;
- a table/equation is unreadably scaled;
- any final page has not been visually inspected when final output is requested.

## House identity

Neutral international academic style. No colored panels, oversized branding, or ornamental decoration unless an external venue requires it.
